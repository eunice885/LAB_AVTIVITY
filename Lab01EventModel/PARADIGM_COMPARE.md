# Paradigm Comparison

## Procedural
The program follows a step-by-step process.
The main program controls the flow.
The search function is called when needed.
The program waits for the search result before continuing.

## OOP
The search form can be represented by an object or class.
The methods handle the search and display the result.
The object controls its own data and behavior.
Async results can be handled by methods or callbacks.

## Event-Driven
The program waits for an event such as form submission.
A handler runs when the user submits the search form.
The search request can run asynchronously.
The result is shown when the response is received.
